## 이용 조건과 제외 자료

KOSHA MSDS는 원문에 표시된 공공누리 제2유형(출처표시·상업적 이용금지)을 메타데이터에 기록했습니다. 현재 교육용 미니 프로젝트를 위한 참고 자료이며, 사업장에서 공급받아야 하는 공급자 MSDS를 대체하지 않습니다.

`reference_only/`의 공급자 PDF 6개는 공개 다운로드 경로에서 확보했으나 문서에 `Business Confidential` 표시가 있어 적재 목록에서 제외했습니다. 프로판·메테인·수소·아세틸렌·이산화황·황화수소 자료이며 OpenAI 임베딩에 전송하지 않았습니다. 실제 적재에는 위 KOSHA 공개 MSDS를 사용했습니다.

## 확인된 차이와 해석 경계

- 프로판의 KOSHA 공개 MSDS 폭발범위는 상한 9.5 / 하한 2.1 %입니다. 기획에서 사용한 하한 2.0 %와 다르므로 원문 수치를 임의로 통일하지 않았습니다.
- 경보 설정의 공식 보완 자료로 C-C-87-2026을 확보했습니다. 7.1(2)에 다단 경보의 폭발하한계 25 % 이하·50 % 이하가 있습니다. 이는 현장 경보를 자동 발령하는 구현 근거로 사용하지 않습니다.
- C-C-87-2026 7.2는 용도에 따라 독성 경보 기준을 구분합니다. 설비 누출 감지는 ERPG-2·AEGL-2·PAC-2·IDLH의 10 % 순위를 적용하고 TLV-C가 있으면 추가 비교합니다. 작업장소 측정은 TWA를 사용합니다. 모든 수치를 단순 최솟값으로 합치는 규칙으로 바꾸지 않았습니다.
- G-78-2021 10.2(13)은 누출 시 출하 중단·시동 정지·점화원 제거, 10.2(14)는 가스 농도 측정과 안전 확인 후 후속 작업을 다룹니다. 후자의 문장에 없는 책임자 승인 문구를 원문에 추가하지 않았습니다. 프로젝트의 경보 발령·해제는 공통 규칙대로 관리자에게 있습니다.
- P-64-2012의 황화철 취급 근거는 5.2.1(2), 탑·탱크 상부 가스 모니터링은 5.3.2(6)에 있습니다. 전자는 물리 8페이지의 원문을 시각 확인했습니다.
