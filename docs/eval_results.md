## 지표 정의 (`RAG/eval/run_eval.py`)

| 지표 | 정의 |
| --- | --- |
| 정확성 | 핵심 질문의 `keywords`가 답변에 **모두** 들어 있는 비율 |
| 키워드 재현율 | 질문별 `keywords` 중 답변에 들어 있는 비율의 평균 |
| 근거성 | 핵심 질문의 `expected_sources` 중 하나가 응답 `sources`에 있는 비율 |
| 무근거 답변률 | 거절하지 않고 답했는데 기대 출처가 응답 `sources`에 없는 비율 (환각률 대용) |
| handoff 적중률 | handoff 질문에서 `handoff=true`이거나 거절 문구로 답한 비율 |

- 평가셋: `RAG/eval/questions.jsonl`. 핵심 질문 10개(기획서 4장)와 handoff 3개이고, 변형 10개는 추가 예정입니다. 기대 답은 기획서 기준이며 원문 재확인이 필요합니다.
- `top_score`(로그)는 FAISS L2 거리입니다. **낮을수록 유사**합니다.

### 0. 기준선 관찰

- **근거성 0%:** 베이스 응답에는 `sources`가 채워지지 않습니다(PR #7에서 필드만 추가, 기본값 `[]`). 사용자는 답변의 근거를 확인할 수 없습니다.
- **문서가 없는 질문(Q3·Q4·Q5·Q6·Q10)은 모두 "찾을 수 없음"으로 거절했습니다.** KOSHA GUIDE·법령이 아직 인덱스에 없으므로 이건 올바른 동작입니다. P1 자료가 들어오면 이 5개가 개선 대상입니다.
- **Q7(암모니아 이격거리) 오답:** PDF에는 "초기이격거리 • 소규모: 반경 30m"가 있는데, 답변은 같은 문서의 "유출 지역 사방 50m 격리"를 썼습니다. 1000자 청크에 여러 항목이 섞여 있어서 생긴 문제로 보입니다. **항목 단위 청킹**(P1)과 **프롬프트의 항목 구분**이 개선 후보입니다.
- **Q8(염소 신고 정보) 오답:** CAS 번호 `7782-50-5`가 답변에 없습니다. 기본 물질 정보 청크가 검색되지 않았습니다.
- **Q2(LEL)는 "정답"으로 셌지만 근거가 없습니다.** P-135가 인덱스에 없는데, LLM이 자체 지식(프로판 LEL 2.1%)으로 답했습니다. 프롬프트가 근거 밖 지식을 막지 못한다는 뜻입니다. 근거성 지표와 함께 봐야 합니다.
- **handoff 3/3은 의미가 약합니다.** 거절 문구로 맞힌 것이고, `handoff` 플래그도 LLM 미호출도 아직 없습니다.

### 1. 응답 계약 관찰

- 답변 문장은 기준선과 같고(프롬프트 미변경), **출처가 보이기 시작하면서 검색 품질 문제가 드러났습니다.**
- **Q8·Q9(염소 질문)의 근거 청크에 `염소.pdf`가 없습니다.** 에틸벤젠·수산화나트륨·메탄올·염산 문서의 "응급조치" 문단이 검색됐고, LLM은 다른 물질 문서로 **일반적으로 맞는 응급조치**를 답했습니다. 기준선에서 Q9를 "정답"으로 센 것은 근거 없는 정답이었습니다. → 다음 변경 후보: **질문의 물질명을 인식해 검색을 그 물질로 제한**(P1 인덱스 `substance` 메타데이터 필터).
- Q7(암모니아)은 `암모니아.pdf`가 3번째 청크에 있어 근거성 1건으로 잡혔지만 답(50m)은 여전히 틀립니다. 같은 청크 안에 "사방 50m 격리"와 "초기이격거리 30m"가 섞여 있습니다. → 항목 단위 청킹(P1 인덱스)으로 개선 기대.
- 무근거 답변률 50% → 40%: Q3~Q6·Q10이 거절로 처리된 것은 같고, Q7이 근거 있음으로 바뀐 차이입니다.
- `top_score`(L2 거리) 분포: 거절된 질문도 상위 거리가 0.45 안팎으로 정상 질문과 크게 다르지 않습니다. 거리 임계값만으로 handoff를 판정하기는 어려워 보이며, 물질 인식과 함께 봐야 합니다.
- 지연 +400ms는 측정 시점 차이 범위로 봅니다(LLM 호출 수 동일).

### 2. P1 정식 인덱스 관찰

- **항목 단위 청킹의 효과가 바로 보입니다.** Q7은 `암모니아.pdf 누출 시 대처요령>초기이격거리` 청크를 근거로 **30m(소규모)·150m(대규모)** 를 정확히 답했습니다(1행까지는 섞인 청크 때문에 50m 오답). Q3(황화수소 TWA 10·STEL 15)·Q5(황화철 모니터링 가스)·Q6(P-64 살수)도 새로 들어온 MSDS·KOSHA 문서로 근거가 잡혔습니다.
- **무근거 답변률 40% → 10%.** 남은 1건은 Q2(LEL): `프로판.pdf 물리화학적 특성>폭발하한범위`가 검색됐지만 P-135(1차 경보 = LEL 25%)가 인덱스에 없어 기대 출처와 다릅니다. P-135는 P1 보완 목록에 없으므로 평가셋 기대 출처를 "프로판 폭발하한범위"로 바꾸는 것이 맞는지 팀 확인 필요.
- **검색 재현율이 병목입니다.** Q1(G-78 10.2(13)), Q4(제618조), Q8·Q9(염소.pdf)는 **문서가 인덱스에 있는데도 상위 5개에 들지 못해** "자료 없음"으로 처리됐습니다. 2,836청크 중 다른 물질의 비슷한 항목(응급조치·누출 대처)이 먼저 잡힙니다. → 다음 변경: **질문의 물질명 인식 → `substance` 메타데이터 필터**, 그 다음 질문 유형별 `doc_type` 필터.
- Q6은 근거(P-64 4.1(3)·5.4(1))는 맞는데 답변에 "2시간·10~15㎥/㎡" 수치가 없습니다. 검색된 절이 5.2.1(2)가 아니어서 생긴 문제 → 검색 개선 후 재확인.
- Q10은 E-G-18·A-G-14·G-78 9.2(12)를 근거로 답했지만 기대 절(G-78 10.2(14))이 아니라 "명시적 언급 없음"으로 답했습니다. 프롬프트가 근거 밖 추론을 하지 않은 것은 바람직하며, 검색이 10.2(14)를 잡으면 해결될 문제입니다.
- 평균 지연 1,750ms: 청크가 짧아져 컨텍스트가 줄었습니다(토큰 입력 감소).

### 3. 물질 인식 검색 제한 관찰

- **Q9(염소 응급조치) 정답·근거 확보.** 2행에서는 `염소.pdf 응급조치>흡입`이 전체 13위라 상위 5개에 못 들었는데, 물질 필터로 염소 청크만 추리면 5위 안에 들어옵니다. 다른 물질(염산·부타디엔)의 "응급조치"가 끼던 문제(1행)도 사라졌습니다.

### 4. 법령 web 인덱스 함께 검색 관찰

### 13. 재작성 어휘표 관찰

- 어휘표를 쓰면 LLM이 관련 없는 어휘까지 끌어오는 경향이 있어(프롬프트 변형 비교에서 Q7이 3→8위로 밀림) "해당하지 않는 어휘는 넣지 말 것"을 명시했습니다. 답변 LLM은 상한(30청크) 안의 청크를 모두 보므로 포함 여부가 순위보다 중요하고, 13행에서 Q7·Q9는 그대로 정답입니다.
- 어휘표는 평가셋 10문항의 현장 표현을 기준으로 만든 것이라 **평가셋에 맞춘 과적합 위험**이 있습니다. 한유진 님 변형 질문 10개가 들어오면 어휘표에 없는 표현으로 일반화되는지 확인해야 합니다.
- 남은 오답: **Q10**은 G-78 10.2(14) 대신 A-G-14 7.1(20)(용접·용단 "책임자 확인 없이 작업 재개 금지")로 답합니다. 내용은 안전 측면에서 틀리지 않지만 기대 절이 아니고, 어휘표의 "가스 감지기 농도 측정" 표현이 Q10 재작성에 들어가도 융합 순위 22위에 그칩니다. **Q8**은 `report_119` 도구 영역.
- 기준선 대비: 정확성 20 → 80%, 근거성 0 → 80%, 무근거 답변률 50 → 0%, handoff 3/3 유지, 지연 2.2 → 3.3초.

### 14. `needs_review` 관찰

- **표시 품질 지표 추가:** 오답(틀림·근거 없음)에서의 표시율과 정답에서의 표시율. 결과 **오답 0/2 표시, 정답 1/8 표시**(3회 동일).
- **잡은 것(Q2):** "LEL 25%가 뭐야? 프로판이면 몇 %vol?"에 LLM이 근거의 2.1%와 질문의 25%로 **0.525%vol을 계산**해 답했습니다. 계산은 맞지만 근거 문서에 없는 파생 수치라 확인 권장으로 표시 — 의도한 동작이고, 발표에서 보여줄 만한 사례입니다. 질문에 있던 숫자(25)는 허용합니다.
- **못 잡은 것(Q8·Q10):** 둘 다 **맞는 문서의 다른 절**로 답한 경우(Q8 염소 이격거리, Q10 A-G-14 용접 지침)라 숫자도 근거에 있고 인용도 달려 있어 숫자·인용 검사로는 구분할 수 없습니다. 이 유형은 절 일치율 지표가 잡고, 해법은 검색(Q10)과 도구 설계(Q8) 쪽입니다.

### 16. 어휘표 항목 제거 — 되돌림

- 15행에서 세운 가설("밀폐공간→적정공기 측정 항목이 Q5-v·Q10-v를 밀폐공간 지침으로 유도")대로 항목을 뺐지만 **Q5-v·Q10-v는 그대로 E-G-18로 답했고, 핵심 Q9(염소 흡입)가 3회 모두 "자료 없음"으로 깨졌습니다**(변형 53%·57%). 재작성 프롬프트 문구가 바뀌면 gpt-4o-mini의 재작성 결과가 달라져 검색 집합이 흔들립니다. 가설이 틀렸으므로 **코드를 13행 상태로 되돌렸습니다.**
