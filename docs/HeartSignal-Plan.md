# HeartSignal - 프로젝트 기획서

# 1. 소개

### 정유·석유화학 현장 가스 경보 대응 에이전트

가스 농도가 경보 기준을 넘으면 **규칙 엔진이 단계를 판정**하고, **에이전트는 사람이 하기 어려운 "찾기·정리·연락" 업무(119 신고, 인근 공장 알림, 구역 방송, 작업반장용 체크리스트)를 문서 근거와 함께 대신 수행**합니다. **사람은 대피 지휘·설비 조작·현장 판단**에 집중합니다.

# 2. 업무 맥락 — 누가, 어떤 상황에서, 무엇을 찾다가 막히는가

## 2.1 사용자

| 사용자                                        | 하는 일                                    | JWT role                         |
| --------------------------------------------- | ------------------------------------------ | -------------------------------- |
| **현장 작업반장** (협력사 정비팀·출하팀 반장) | 작업 지휘, 경보 시 **대피 지시·인원 점검** | `foreman`                        |
| **현장 작업자** (신입 운전원·협력사 작업자)   | 작업 수행, 작업 전 안전 질문               | `worker`                         |
| **안전관리자** (관제실)                       | 경보 감시, 비상조치 가동, 대외 연락 책임   | `admin`                          |
| **운전원** (DCS 조작)                         | 차단밸브·비상정지(ESD) 등 **설비 조작**    | 서비스 사용자 아님 (역할만 명시) |
| **가스 센서** (가상)                          | 농도 이벤트 전송                           | `device`                         |

## 2.2 업무 장면과 막히는 지점

| #   | 누가                 | 업무 상황                                        | 무엇을 찾다가                                                        | 어디서 막히나                                                                                                                 | HeartSignal 연결                                                                                                    |
| --- | -------------------- | ------------------------------------------------ | -------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |

| W4  | 안전관리자           | 3단계 경보, 119 신고                             | "물질명·UN번호·CAS·농도·위치·이격거리를 정리해서 말해야 함"          | 신고 정보가 MSDS·안전지침·관제 화면에 흩어짐. 신고 중에는 현장 지휘 불가                                                      | 에이전트가 **안전지침 PDF 기본정보 + 센서값 + 구역 정보**로 신고문 작성·발송 (관리자 보류 가능)                     |
| W5  | 안전관리자           | 독성가스 누출, 인근 사업장 통보                  | "바람 방향 몇 m까지 위험? 어느 공장에 알려?"                         | 초기이격거리가 물질마다 다르고, 인근 사업장 연락망은 엑셀에 있음                                                              | 에이전트가 안전지침 **초기이격거리** 근거로 반경 내 사업장(`contacts.json`)에 **알림 발송**                         |
| W6  | 신입 운전원          | 경보 화면에 "LEL 25%" 표시                       | "LEL 25%가 무슨 뜻? 지금 몇 %vol이야?"                               | 단위·용어를 모름                                                                                                              | 경보 카드에 **판정 근거(기준값·출처)**를 쉬운 말로 표시                                                             |

> **핵심 통찰:** 경보 상황에서 사람이 막히는 이유는 "지식 부족"보다 **찾고·정리하고·연락하는 일과 대피 지휘가 같은 시간에 몰리는 것**입니다. 그래서 에이전트는 **찾기·정리·연락**을 맡고, 사람은 **사람만 할 수 있는 일(대피 지휘·설비 조작·현장 판단)**을 맡습니다.

# 3. 단계별 대응 — 사람과 에이전트의 역할 분리 ⭐

## 3.1 원칙

| 누가                              | 하는 일                                                                                                  | 절대 하지 않는 일                                    |
| --------------------------------- | -------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| **규칙 엔진**                     | 기준표(`thresholds.json`)로 경보 단계 판정                                                               | 문구 생성                                            |
| **에이전트 (RAG + Tool Calling)** | 문서 검색 → 방송 문구·체크리스트·신고문 작성 → **119 신고, 인근 공장 알림, 구역 방송, 담당자 알림 실행** | 경보 단계 판정·해제, 대피 판단, 설비 조작, 의료 판단 |
| **작업반장**                      | 작업 중지·**대피 지시·인원 점검**, 현장 재측정                                                           | 신고·대외 연락 (에이전트가 대신)                     |
| **안전관리자**                    | 비상조치 가동, **119 신고 보류(30초 내)**, **경보 해제**, 재개 승인                                      | —                                                    |
| **운전원**                        | 차단밸브·ESD 등 설비 조작                                                                                | —                                                    |

- 에이전트가 쓰는 **모든 대응 문장은 `rag_search` 결과 문서에서 가져오고 출처를 붙입니다.** 근거가 없으면 해당 문장을 빼고, 고정 템플릿 문구만 씁니다.
- **LLM 장애 시에도** 규칙 엔진 판정 + 고정 템플릿으로 방송·신고·알림은 동작합니다. (에이전트가 없어도 경보는 멈추지 않음)

## 3.2 단계별 역할표

| 단계          | 판정 (규칙 엔진)                                     | 🤖 에이전트가 하는 일 (도구)                                                                                                                                                                                                                                                                                        | 👷 작업반장                                                   | 🧑‍💼 안전관리자                                  | 🔧 운전원             |
| ------------- | ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- | ---------------------------------------------- | --------------------- |
| 🟡 **1 주의** | TWA 초과 또는 5분 연속 상승 추세                     | ① `rag_search`로 물질·작업 상황 대응 문서 검색 ② `broadcast_tts` 해당 구역 **주의 방송** ③ `notify_foreman` 반장 단말에 **점검 체크리스트**(재측정·점화원 확인) ④ `notify_manager` 관제 알림                                                                                                                        | 휴대용 검지기로 **재측정**, 작업 계속/일시중지 판단           | 관제 화면 확인                                 | 공정 이상 여부 확인   |
| 🟠 **2 경고** | 공식 1차 경보 (LEL 25%, P-136 경보값, 산소 18% 미만) | ① `broadcast_tts` **작업 중지·점화원 제거·대피 준비** 방송 (문서 근거) ② `notify_foreman` **대피 경로·집결지·인원 명단** 체크리스트 ③ `notify_manager` 비상조치 가동 요청 ④ 인접 구역에 **사전 경고** 방송                                                                                                          | **작업 중지 지시**, 보호구 착용, **대피 지시·인원 점검** 시작 | 비상조치계획 가동 판단, 출하 중단 지시         | 차단밸브 준비         |
| 🔴 **3 위험** | IDLH 또는 LEL 50%                                    | ① `report_119` **119 신고문 작성 → 30초 보류창 → 발송** (물질·UN·CAS·농도·위치·인원 현황) ② `notify_neighbors` 초기이격거리 반경 내 **인근 공장 알림** ③ `broadcast_tts` **전 구역 대피 방송** ④ `build_briefing` 소방 도착 시 **브리핑 카드**(MSDS 요약) ⑤ 반장이 입력한 **인원 점검 결과를 119 후속 보고에 반영** | **대피 유도, 인원 점검 결과 입력**("12/12 확인")              | **신고 보류(오경보 시)**, 현장 지휘, 소방 인계 | **ESD·차단밸브 조작** |
| ⬜ **해제**   | 농도가 내려가도 자동 해제 안 함                      | `broadcast_tts` 해제 방송, 감사 로그 마감, 재개 조건 체크리스트(문서 근거) 제공                                                                                                                                                                                                                                     | 재측정 결과 보고                                              | **경보 해제·작업 재개 승인**                   | 설비 정상화           |
